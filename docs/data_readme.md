# 数据说明（预埋风险剧本 / 答案底稿）

> ⚠️ 合规声明：本目录全部数据为**虚构**。项目、公司、人物、预算、排期、合同均为合成数据，
> 不使用任何真实公司内部文档、合同、艺人信息或未上映内容。
> 生成脚本：`scripts/make_synthetic_data.py`（幂等、可复现、带自检）。
>
> 本文件是 Demo 的"答案底稿"：每个预埋风险的正确结论、应引用位置、期望置信度。
> 黄金集标注时以此为参考答案（先人后模型：先自己从数据里找答案，再看本表）。

## 使用规范

- 黄金集/边界集评估答案以本表为底稿；标注时先自己从数据里找答案，再看本表
- 每次修改 `make_synthetic_data.py` 后必须重跑（自带预埋风险自检），并同步更新本表
- 数据文件可提交 git（合成数据，非敏感）；`.env` 等密钥类绝不提交
