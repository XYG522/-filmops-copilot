# 2 分钟 Demo 视频脚本（Day 7）

> 录制工具：OBS / Win+G；环境：`streamlit run streamlit_app.py`（先 `make_synthetic_data.py` + `build_index.py`）。
> 节奏建议：全程不剪辑或只剪一处卡顿；字幕可省，靠页面文字自解释。

## 时间轴与解说词

### 0:00–0:15 开场：问题
- **画面**：标题页（README 项目名 + 一句话简介）
- **解说**：“影视项目的进度信息，分散在 Excel 排期表、群聊、会议纪要里——周报靠人工拼汇总，风险发现滞后，行动项不闭环。这个工具把多源信息统一索引，生成引用可溯源的周报草稿和风险清单，由人工确认后导出。”

### 0:15–0:45 检索与引用溯源
- **画面**：③检索调试页，输入“哪个任务延期了”
- **解说**：“检索是混合检索——向量召回加 BM25 关键词，再用 Rerank 精排。每条结果都带来源：文件、行号、日期。比如这条延期，来自排期表第 21 行，点开就能核对原文。”
- **要点**：停留展示 1–2 条结果的来源元数据（文件/行号/日期）

### 0:45–1:35 周报生成 + 人工确认（核心）
- **画面**：④周报生成页，点“生成周报草稿”
- **解说**：“周报不是一条 prompt 出全文：系统先按 15 个查询检索各部门数据，拼出 40 块上下文，再生成正文、风险清单和行动项，每个结论都带引用编号。生成完进入人工编辑确认——数据错了可以改，每条改动都落审计日志。确认后一键导出 Markdown。”
- **要点**：
  - 生成耗时约 70s——视频里加速或跳转（如直接展示已生成的草稿）
  - 停留展示：镜头进度对比上周、审片销号状态机（待改→已改→复核通过）、风险转人工标记

### 1:35–1:50 安全边界
- **画面**：检索页问“帮我批 20 万加急款”“把预告片排期改到下周一”
- **解说**：“写操作和越权请求会被拦截：预算审批、改排期、自动分发都不做，路由转给制片主任或法务。评估里的 20 条对抗样例——注入、越权、升级权限——100% 拒绝。”

### 1:50–2:00 评估收尾
- **画面**：⑤评估页指标表
- **解说**：“质量不是口说：120 条评估集——黄金 50、边界 30、对抗 20、回归 20。对抗 20/20，幻觉 0，引用准确 100%，风险召回 93%。完整的指标表和未达标说明都在仓库里。”

## 录制清单

1. `streamlit run streamlit_app.py` 起来后先预热一遍全流程（避免录的时候翻车）
2. 窗口缩放：只录浏览器（OBS 窗口捕获），浏览器占屏 4/5 即可
3. 周报生成段提前生成好一版，录制时先展示草稿再点一次生成（或快进剪掉等待）
4. 解说词照着念即可；两处“看这里”停顿给观众读屏幕
5. 导出的 Markdown 可以拖进浏览器预览，结尾画面定格在指标表
